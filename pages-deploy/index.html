Questions, answered plainly.

Where is my resume processed?

Local keyword matching and text checks run in this tab. Optional AI review and rewrite send your resume and job description for external processing only when requested. See the scoring and data-handling explanation before using AI features.

Is this the same score every ATS uses?

No. There is no universal ATS score. This directional simulation combines exact words from this job description with four raw-text parseability checks; the separate HR lens comes from the AI review.

Does the demo use AI?

Yes. AI Deep Review uses a small model through Cloudflare Workers AI, and AI Rewrite uses DeepSeek through the same server-side Worker. No API key is entered in the browser.

Can it read a PDF?

Yes. Choose a text-based PDF and the demo will extract its text in your browser. Image-only scanned PDFs require OCR, which is not included here.

Is CheckATS free, and do I need an account?

Local checks are free and require no account. Standard AI allowances are 5 review requests and 2 rewrite requests per IP per UTC day. Shared networks share the allowance; automatic review refreshes also use review requests.

ATS checks stay local. AI Deep Review and AI Rewrite send the resume and job description to the Cloudflare Worker only when requested; the DeepSeek key stays on the server. Results are guidance, not a guarantee of hiring outcomes.
